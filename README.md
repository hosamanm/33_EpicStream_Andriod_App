# 🎬 OTT Stream

A production-ready OTT (Over-The-Top) Video Streaming Platform built with Flutter and Firebase.

The platform allows users to stream licensed video content with watchlists, downloads, notifications, and an admin panel for content management. All content is accessible to registered users.
